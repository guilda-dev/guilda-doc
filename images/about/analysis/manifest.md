# About carousel: 解析を助ける機能

Media of the carousel of analysis features in the About tab, one item per feature card
(01 to 03) and one more analysis aid (04). Each video records an analysis done with GUILDA
and drawn by its `plot_*` methods (GraphBase). All are regenerated by
`notes/about-anim/make_about_analysis.m` in the guilda repository (R2026a, ffmpeg):

```matlab
addpath("notes/about-anim"); make_about_analysis(OutDir="<docs>/images/about/analysis");
```

Videos: MP4 (H.264, yuv420p, faststart), 1280 x 640 px, 20 frames/s, each with a PNG
poster of the same name. The pointer and the blue click rings in 01 are drawn onto the
recorded frames to show where the script clicked. Added by the script on the figures: the
zoom of the eigenvalue maps, the gray markers of a reference state (02, 03), the line of the
damping-ratio limit (03), the titles of the maps and the command strip (02), the bottom line
of 03 (values of `res.sct_stability.tab_iteration`), the dispatch title of 03 for iterations
1 to 3 (plot_dispatch writes "not solved" for their flag 0, the limit not yet met, although
each OPF was solved) and the step label of the instability line
and the x labels in 04. Everything else is the figure as GUILDA draws it.

## 01 要素ごとの減衰への寄与

- file: `01-contribution.mp4`
- poster: `01-contribution.png`
- type: interactive (12.3 s)
- card: 要素ごとに分解できる線形モデル / A linear model taken apart by element
- heading JA: モードの減衰を要素ごとに分ける
- heading EN: The damping of a mode, element by element
- JA: IEEE 68 母線系統（AVR と PSS 付き）の線形モデルを要素ごとの和に分け、固有値マップでクリックしたモードの減衰に各要素がどれだけ寄与しているかをネットワーク図に色で示します。0.41 Hz の地域間モードでは、減衰を増やす発電機と減らす発電機が分かれます。母線をクリックすると、その母線の発電機・AVR・PSS ごとの値が表に出ます。
- EN: The linear model of the IEEE 68-bus system (with AVRs and PSSs) is split into the parts of its elements, and the network diagram colors how much each element adds to or removes from the damping of the mode clicked on the eigenvalue map. In the 0.41 Hz inter-area mode some generators add damping and others remove it. Clicking a bus lists the values of its generator, AVR and PSS in the table.
- code:

```matlab
net = network.IEEE68bus(LocalController=true);   % AVR (avr-ST1) and PSS (pss-PSS1) on every generator
res = net.get_sys();
sct = res.plot_contribution();                    % click a mode, then a bus
res_g = res.get_contribution("B016SG1");          % the part of one generator, as a ResultLIN
```

## 02 PSS を追加して固有値と時間応答を比べる

- file: `02-controller-pss.mp4`
- poster: `02-controller-pss.png`
- type: animation (13.3 s)
- card: 制御器もネットワークの一部 / Controllers in the same network
- heading JA: 制御器を追加して、同じモデルで解析し直す
- heading EN: Add a controller and analyze the same model again
- JA: IEEE 68 母線系統で、AVR だけの状態から発電機に PSS を 1 台ずつ追加します。追加のたびに初期化して近似線形化と事故の時間応答シミュレーションを実行し、固有値と各発電機の角周波数偏差の変化を示します。AVR だけでは不安定な固有値がありますが、12 台目の追加ですべての固有値の実部が負になります。
- EN: Starting from the IEEE 68-bus system with AVRs only, a PSS is added to one generator after another. After each addition the network is initialized, linearized and simulated for a fault, and the eigenvalues and the frequency deviation of the generators follow. With AVRs only some eigenvalues are unstable; from the twelfth PSS on, every eigenvalue has a negative real part.
- code:

```matlab
net = network.IEEE68bus(LocalController=true);
for i = 1:16                                      % AVRs only: remove the PSSs
    gen = net.a_Bus{i}.a_Component{1};
    gen.remove_local_controller(gen.pss.s_tag);
end
sc = net.add_scenario("fault", Time=[0, 15]);
sc.add_fault("B001", [1, 1.05]);
prm = struct(kpss=25, tWS=10, tn1=0.07, td1=0.02, tn2=0.07, td2=0.02);
for i = 1:16
    net.a_Bus{i}.a_Component{1}.add_local_controller("pss-PSS1", parameter=prm);
    net.initialize();
    lin = net.get_sys();  lin.plot_eigenvalue();
    sim = net.simulate("fault");  sim.plot_trajectory(Quantity="omega");
end
```

## 03 小信号安定度制約付き最適潮流計算

- file: `03-stability-opf.mp4`
- poster: `03-stability-opf.png`
- type: animation (10.9 s)
- card: 最適化と安定性を一つのモデルで / One model from optimization to stability
- heading JA: 減衰比の下限を満たす最適潮流
- heading EN: An optimal power flow that meets a damping-ratio limit
- JA: IEEE 14 母線系統の AC 最適潮流計算に、最小減衰比 0.048 の制約を加えます。外側の反復ごとに解で近似線形化し、電気機械モードの固有値が減衰比 0.048 の線（破線）を越えるまで動作点が変わる様子を、右の発電出力・電圧とともに示します。灰色は制約なしの最適潮流の固有値です。4 回目の反復で最小減衰比は 0.0481 になり、コストは 8081.5 から 8566.7 に上がります。
- EN: A lower limit of 0.048 on the damping ratio is added to the AC optimal power flow of the IEEE 14-bus system. The network is linearized at the solution of each outer iteration: the operating point moves (dispatch and voltages on the right) until the electromechanical eigenvalues cross the dashed line of damping ratio 0.048. Gray: the eigenvalues of the OPF without the limit. At the fourth iteration the smallest damping ratio is 0.0481 and the cost rises from 8081.5 to 8566.7.
- code:

```matlab
net = network.IEEE14bus();
net.initialize();
[res, flag] = net.calculate_optimal_powerflow(Method="AC OPF", MinDampingRatio=0.048);
res.sct_stability.tab_iteration                   % cost and smallest damping ratio of each outer iteration
res.plot_dispatch();
net.initialize(Method="OPF", MinDampingRatio=0.048);   % the solution as the operating point
lin = net.get_sys();
lin.plot_eigenvalue();
```

- note: the solution of outer iteration k is the result with `StabilityMaxIteration=k`; the
  script builds its point as the stability-constrained OPF does (the P of the generators and
  the V of their buses as power flow set points, then `net.initialize`) and checks that the
  smallest damping ratio of the linearization equals `tab_iteration.MinDampingRatio`
  (0.0447, 0.0454, 0.0467, 0.0481).

## 04 連続潮流計算の各ステップで近似線形化する

- file: `04-cpf-eigenvalue.mp4`
- poster: `04-cpf-eigenvalue.png`
- type: animation (8.7 s)
- card: (more analysis aid)
- heading JA: 負荷を増やしながら小信号安定性を調べる
- heading EN: Small-signal stability while the load grows
- JA: IEEE 14 母線系統で母線 B009 と B014 の負荷を増やす連続潮流計算を行い、各ステップの動作点で近似線形化します。固有値マップ、PV 曲線、固有値の最大実部と最小減衰比のグラフが同じステップに連動します。このモデル（界磁電圧と機械入力が一定）では、ノーズ（λ = 5.21）より手前の λ = 3.11 で実固有値が正になります。
- EN: A continuation power flow of the IEEE 14-bus system increases the loads at buses B009 and B014, and the network is linearized at the operating point of each step. The eigenvalue map, the PV curves and the chart of the largest real part and the smallest damping ratio follow the same step. In this model (constant field voltage and mechanical input) a real eigenvalue becomes positive at λ = 3.11, before the nose at λ = 5.21.
- code:

```matlab
net = network.IEEE14bus();
net.initialize();
cpf = net.calculate_continuation_powerflow(LoadBus=["B009", "B014"]);
lin = net.get_sys({cpf, 1:cpf.r_noseStep});       % one section per step
G = lin.plot_eigenvalue();
G.link(cpf.plot_pvcurve());
G.link(lin.plot_eigenvalue_path());
G.set_time(104);                                  % the step where Re λ first exceeds 0
```
